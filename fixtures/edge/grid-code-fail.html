Caching fetch calls

Wrap the call once and every page reuses the result.

export async function cachedFetch(url: string, options: RequestInit = {}, ttlSeconds = 300): Promise<Response> { const key = [url, JSON.stringify(options)].join("|"); return memo(key, ttlSeconds, () => fetch(url, options)); }

The key includes the options, so a POST never reads a cached GET.
